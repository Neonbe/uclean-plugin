# 场景与按钮

每次只给 1–2 个主操作。列表里的勾选、说明折叠和单个废纸篓恢复是项目操作，不增加主流程分支。所有清理先展示精确预览；扫描、选择和生成预览都不会删除目标。

| 场景 | 行为 | 主按钮 |
|---|---|---|
| AI 构建/安装/下载遇到 ENOSPC | 测量当前空间，快速扫描已知缓存；不安装自动执行钩子 | 一键清理 / 深度查找 |
| 用户主动清理 | 默认目标为至少 10 GB 可用，可选择 20/50/100 GB | 快速检查 / 直接深度查找 |
| 快扫有可用项 | 优先低风险、分配空间大的缓存；生成精确计划 | 一键清理 / 继续清理 |
| 计划已生成 | 展示数量、完整路径、容量、永久删除与废纸篓分项及后果 | 确认本次清理 / 返回选择 |
| 用户更改选择 | 废弃旧预览，重新生成范围与确认值 | 确认新计划 / 返回选择 |
| 第一轮结束但不足 | 测量剩余差距，进入推荐层 | 继续清理 / 暂时结束 |
| 推荐层发现有成本的缓存 | 不默认勾选；解释重新下载、构建、旧设备调试的影响 | 预览所选项目 / 深度查找 |
| 第二轮仍不足 | 扩大只读扫描：项目产物、大文件、模型、备份、虚拟磁盘 | 深度查找 / 暂时结束 |
| 深度仍不足或只有分析项 | 给工具专用操作建议；可以迁移文件到外置盘 | 查看占用与建议 / 结束 |
| 找到大文件 | 展示路径、分配空间和用途未知；不判作垃圾 | 查看建议 / 结束 |
| 旧安装包 | 用户选择后进废纸篓；默认只考虑 Downloads 顶层、30 天以上安装包 | 预览所选项目 / 继续查找 |
| 只有废纸篓移动，空间未增加 | 明确同卷移动未释放；让用户在 Finder 检查 | 查看废纸篓说明 / 继续清理 |
| 用户想撤销 | 仅恢复仍在废纸篓且身份未变的安装包；不覆盖同名文件 | 恢复该文件 / 保留现状 |
| 达到空间目标 | 显示实测可用空间，可回到原任务 | 完成 / 继续清理 |
| 这一层没有候选 | 继续下一层，不呈现虚假 0 B 全盘结论 | 继续清理或深度查找 / 结束 |
| 应用/构建占用 | 保留占用项，不杀进程；用户退出后重试 | 已退出，重新检查 / 继续查找 |
| 权限不足 | 说明未检查范围，用户通过系统设置授权 | 重新检查 / 继续查找 |
| 超时/数量/深度上限 | 显示部分结果与未扫描范围，不能执行不完整候选 | 重新检查 / 继续查找 |
| 文件变化/符号链接/保护路径 | 拦截该项；不能通过更高风险层覆盖 | 重新扫描 / 结束 |
| 计划过期或已执行 | 拒绝重复 apply，必要时读取 receipt | 重新扫描 / 结束 |
| 部分删除失败 | 逐项显示成功/跳过/部分成功，保留 staging 恢复路径 | 查看未完成项目 / 继续查找 |
| 取消扫描 | 无目标修改，废弃不完整结果 | 重新扫描 / 结束 |
| 取消清理 | 停止后续项；正在删除的项可能部分完成，不承诺回滚 | 查看结果 / 结束 |
| 程序中断 | 计划标记已使用/执行中，不自动重放；verify 检查日志 | 查看记录 / 结束 |
| 清理后空间变少或增加不符 | 显示真实有符号差值，说明并发写入/APFS共享/快照 | 深度查找 / 结束 |
| 面板失联或会话到期 | 不追加操作，从插件重新开启会话；旧任务先 verify | 重新打开 / 结束 |
| 不支持的平台/缺少 Python | doctor 给出诊断，保留任务，不用临时 rm 替代 | 修复运行环境 / 结束 |

## 检出范围

quick 默认最多 20 秒：并行检查 16 类精确缓存路径；单目标 8 秒预算。
recommended 默认最多 40 秒：包含 quick，增加重建成本较高的工具数据和旧安装包。
deep 默认最多 90 秒：包含前两层，元数据遍历 Developer、Projects、Code、src、Desktop、Downloads（最多 6 层、50,000 目录项），同时测量额外大型占用。单候选最多 400,000 项，单目标 12 秒预算。预算约束元数据遍历循环，操作系统阻塞的单次调用不保证硬实时返回。CLI `--budget` 最大 300 秒。

已知路径缺失不当作错误；权限拒绝、深度/数量/时间预算会记录。大文件仅按元数据判断，不读取内容，不做重复文件哈希。硬链接的分配空间从释放估算中排除；APFS 克隆/快照共享无法仅凭元数据精确判断，以执行后的磁盘可用变化为准。

## 0.1 的明确边界

支持精确目录缓存删除，首版不运行 Homebrew/npm/pip 的整类 purge 命令，因为它们可能扩展到未确认的配置路径或触发可执行配置。uv、pnpm store 和 Maven 可能包含共享/本地唯一内容，仅分析并给出工具原生命令建议。项目产物必须有标记文件、Git 忽略证据且没有 Git 跟踪内容；这仍不是备份或未提交内容的语义证明，所以属于深度显式选择项。不会识别所有自定义缓存位置；不会声称已经穷尽磁盘。
